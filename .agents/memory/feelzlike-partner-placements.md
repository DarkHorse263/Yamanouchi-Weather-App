# Paid partner placements (transport)

**Rule:** `TransportProvider.partner: true` = a PAID, signed listing deal. It renders a disclosed "Featured partner" label (Handshake icon, JA 提携パートナー) and flips outbound links to `rel="sponsored"`. `featured: true` alone = editorial spotlight (unlabeled Star "Featured"), e.g. Cooma Coaches today.

**Why:** honesty-first brand. Paid placement must always be disclosed; competitors are never demoted/removed because someone paid; free listings stay free; weather/snow/road data never influenced by money. Never set `partner` without a signed agreement — it was demoed once and immediately reverted.

**How to apply:**
- Wired in 3 surfaces that must stay in sync: generic `TownTransport` (FeaturedProviderCard + ProviderLinks), bespoke SnowyTransport (Cooma hero + SMBS link + local ProviderCard), bespoke VHC Transport (hero + multiResortHero + local ProviderCard). Any new transport surface must honor both the badge and the sponsored rel.
- Turning a deal on = add `partner: true` to the provider record in the region's transport data file.
- SECOND SURFACE: town home page (data = `data/townPartners.ts` keyed by kebab town id, one partner per town, record EMPTY until a deal signs). Two render styles chosen per deal via `display`: "listing" (default, quiet `TownPartnerCard` below weather content) or "ad" (`TownPartnerAd` rotating banner directly under the town header, cycles tagline+messages every 4.5s, reduced-motion pins the tagline). Optional `brand` (logo + gradient colours + theme + CTA colours) makes the ad wear the PARTNER's identity; house blue is the fallback. Disclosure label stays visible under any branding. Partner logos must be owner-hosted before a real entry goes live (hotlinks rot + leak visitor IPs).
- Snowball Japan Properties (Madarao/Tangram chalets) placement is DEFERRED: no Madarao stays surface exists; build it only when their deal signs (they fund their own shopfront — don't build on spec).
- Deal docs (rate card, one-page agreement template, owner playbook) are generated by `build-partner-docs.ts` into `exports/` — PRIVATE owner docs, never copied to public/downloads, never linked in-app.
- CLICK TRACKING: partner links carry UTM tags (`withPartnerUtm` · utm_source=feelzlike, utm_campaign=<town>-<placement>) so the PARTNER's analytics proves feelzlike traffic at renewal time, plus a `partner_click` event through the `track()` seam (never direct gtag). GA4 only shows the partner/town/placement params after the OWNER registers them as custom dimensions in GA — remind them when the first deal signs. UTM covers middle-click/context-menu opens that the click event misses.
