# Paid partner placements (transport)

**Rule:** `TransportProvider.partner: true` = a PAID, signed listing deal. It renders a disclosed "Featured partner" label (Handshake icon, JA 提携パートナー) and flips outbound links to `rel="sponsored"`. `featured: true` alone = editorial spotlight (unlabeled Star "Featured"), e.g. Cooma Coaches today.

**Why:** honesty-first brand. Paid placement must always be disclosed; competitors are never demoted/removed because someone paid; free listings stay free; weather/snow/road data never influenced by money. Never set `partner` without a signed agreement — it was demoed once and immediately reverted.

**How to apply:**
- Wired in 3 surfaces that must stay in sync: generic `TownTransport` (FeaturedProviderCard + ProviderLinks), bespoke SnowyTransport (Cooma hero + SMBS link + local ProviderCard), bespoke VHC Transport (hero + multiResortHero + local ProviderCard). Any new transport surface must honor both the badge and the sponsored rel.
- Turning a deal on = add `partner: true` to the provider record in the region's transport data file.
- SECOND SURFACE: town home page (data = `data/townPartners.ts` keyed by kebab town id, one partner per town, record EMPTY until a deal signs). THIRD SURFACE: region page (`REGION_PARTNERS` in the same file, keyed by region id, rendered directly under the region header on the base-town picker; same components, same rules, also EMPTY). Two render styles chosen per deal via `display`: "listing" (default, quiet `TownPartnerCard` below weather content) or "ad" (`TownPartnerAd` rotating banner directly under the town header, cycles tagline+messages every 4.5s, reduced-motion pins the tagline). Optional `brand` (logo + gradient colours + theme + CTA colours) makes the ad wear the PARTNER's identity; house blue is the fallback. Disclosure label stays visible under any branding. Partner logos must be owner-hosted before a real entry goes live (hotlinks rot + leak visitor IPs).
- LIVE (owner-approved July 2026, `townPartners.ts`): Snoexpress "ad" (owner-hosted transparent red wordmark; tagline avoids repeating the logo's "your link to the snowfields" slogan) on snowy-mountains region + jindabyne/berridale/cooma towns; Snowball Japan "ad" (owner-hosted square logo asset, light theme) on iiyama + yamanouchi regions + madarao-kogen town. Transport-list `partner:true` for au-snoexpress NOT set (banner-only deal so far). OWNER DECISION: every partner panel uses the shared logo-light-blue `PARTNER_BLUE` background (partner identity = logo chip only, no per-partner panel colours) so placements stand out consistently.
- Deal docs (rate card, one-page agreement template, owner playbook) are generated by `build-partner-docs.ts` into `exports/` — PRIVATE owner docs, never copied to public/downloads, never linked in-app.
- CLICK TRACKING: partner links carry UTM tags (`withPartnerUtm` · utm_source=feelzlike, utm_campaign=<place>-<placement>, place = town id OR region id) so the PARTNER's analytics proves feelzlike traffic at renewal time, plus a `partner_click` event through the `track()` seam (never direct gtag). GA4 only shows the partner/place/placement params after the OWNER registers them as custom dimensions in GA (param key is `place`, not `town`) — remind them when the first deal signs. UTM covers middle-click/context-menu opens that the click event misses.
